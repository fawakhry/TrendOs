## Project separation rule

- كل مشروع يحتفظ بتفاصيله داخل Repository/Branch الرسمي الخاص به.
- هذا الفهرس يحتفظ فقط بالاسم، الحالة العامة، Repository/Source، والـCanonical Branch.
- لا تحفظ هنا Cases أو Decisions أو Rules أو Assets أو Knowledge تفصيلية لأي مشروع.
- عند الحاجة لتفاصيل مشروع، انتقل إلى مصدره الرسمي.
- لا تنشئ Branch إضافي لمشروع له Repository مستقل بالفعل لمجرد الفصل؛ الـCanonical Branch المسجل هنا هو المرجع.
