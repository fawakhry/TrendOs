# Fokha Decisions — Global Only

> هذا السجل يحتفظ فقط بالقرارات العامة التي تخص إدارة عدة مشاريع.
> Updated: 2026-09-12.

## Global decisions

### Fokha as portfolio layer
- Fokha هو طبقة الإدارة العليا بين المشاريع، وليس بديلًا عن ذاكرة أي مشروع.

### Source separation
- كل مشروع يحتفظ بذاكرته وقراراته وتفاصيله داخل مصدره الرسمي المستقل.
- Fokha يحتفظ فقط بالروابط والخطوط العريضة المشتركة.

### Evidence hierarchy
- أحدث Evidence متحقق داخل المشروع يتغلب على الملخصات أو الذاكرة العامة القديمة.

### Safe execution
- القرارات التشغيلية الصغيرة والقابلة للرجوع يمكن تنفيذها وفق قواعد المشروع.
- القرارات الجوهرية أو غير القابلة للرجوع تبقى تحت سلطة المستخدم النهائية.
