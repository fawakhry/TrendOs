# عقل فوخا — اقرأني أولًا

> هذا هو مدخل عقل فوخا المؤقت على GitHub إلى أن يتم إنشاء Repository مستقل باسم `Fokha`.

أي Chat / AI Agent يُطلب منه: **«روح على GitHub عقل فوخا»** يجب أن يبدأ من هذا الملف قبل أي تحليل أو تنفيذ.

## الهدف

عقل فوخا ليس أرشيف محادثات. الهدف هو تحويل الشغل، المحادثات، القرارات، الأكواد، الملفات، والتجارب إلى معرفة وداتا قابلة لإعادة الاستخدام في الإدارة واتخاذ القرار وتشغيل المشاريع.

المسار الأساسي:

`RAW INPUT -> EVIDENCE -> EXTRACTED DATA -> KNOWLEDGE -> RULES / DECISIONS / PROJECT LINKS -> REUSE`

## ترتيب القراءة الإجباري

1. هذا الملف: `FOKHA_BRAIN/اقرأني_أولا.md`
2. برومبت الاستخراج: `FOKHA_BRAIN/PROMPTS/برومبت_استخراج_المعرفة_والداتا.md`
3. قواعد الحوكمة: `FOKHA_BRAIN/STANDARD/FOKHA_EXTRACTION_STANDARD.md`
4. Standard التشغيل القادم من Google Sheet: `FOKHA_BRAIN/STANDARD/FOKHA_WORKING_STANDARD.md`
5. فهرس الذاكرة المنظمة: `FOKHA_BRAIN/MEMORY/INDEX.md`
6. عند الحاجة لفهم طريقة التفكير الحالية: `FOKHA_BRAIN/MEMORY/THINKING_MODEL.md`
7. اقرأ `RULES.md` و`DECISIONS.md` و`PROJECTS.md` و`SOURCE_LINKS.md` حسب المهمة.
8. عند العمل على مشروع محدد: اقرأ ذاكرة المشروع الرسمية نفسها، ولا تستبدلها بعقل فوخا.

## قاعدة الفصل

- **Fokha Brain** = عقل تنفيذي عام فوق كل المشاريع.
- **Project Memory / Black Box** = الحقيقة التنفيذية الخاصة بكل مشروع.
- عقل فوخا يستخرج المعرفة العامة والأنماط والروابط، لكنه لا ينسخ أو يغيّر حقائق المشروع الحية بدون مصدر موثوق.

## عند بدء أي Chat جديد

إذا قال المستخدم: **«روح على جيت هب عقل فوخا»** أو ما يعادلها:

1. اقرأ هذا الملف كاملًا.
2. اقرأ برومبت الاستخراج كاملًا.
3. اقرأ Memory Index والملفات المرتبطة بالمهمة.
4. حدّد المشروع من `PROJECTS.md` ومصدر الحقيقة من `SOURCE_LINKS.md`.
5. اقرأ المشروع أو المصدر المطلوب من مصدره الرسمي.
6. استخرج المعرفة والداتا المفيدة وفق البرومبت.
7. افصل بوضوح بين:
   - حقيقة صريحة.
   - قرار صريح.
   - قاعدة مستخلصة.
   - استنتاج AI يحتاج تأكيد.
   - فكرة أو فرصة.
   - معلومة تخص مشروعًا بعينه.
8. لا تخترع شيئًا غير موجود في الأدلة.
9. اربط كل عنصر بمصدره أو مرجعه متى كان متاحًا.
