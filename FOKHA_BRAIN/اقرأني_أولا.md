# عقل فوخا — اقرأني أولًا

> هذا المسار طبقة Portfolio عامة فقط. لا يخزن تفاصيل المشاريع.

## وظيفة عقل فوخا

- فهرسة المشاريع.
- حفظ المبادئ العامة المشتركة.
- حفظ روابط المصادر الرسمية.
- توجيه أي Chat/Agent إلى ذاكرة المشروع الصحيحة.

## قاعدة الفصل

- كل مشروع يحتفظ بذاكرته وقراراته وقواعده وتفاصيله داخل Repository/Branch رسمي مستقل.
- FOKHA_BRAIN يحتفظ فقط بالخطوط العريضة.
- عند العمل على مشروع محدد، انتقل مباشرة إلى مصدره من `FOKHA_BRAIN/MEMORY/PROJECTS.md`.
- لا تنسخ Cases أو Assets أو Decisions أو Rules أو Knowledge تفصيلية من مشروع إلى FOKHA_BRAIN.

## ترتيب القراءة

1. `FOKHA_BRAIN/MEMORY/INDEX.md`
2. `FOKHA_BRAIN/MEMORY/PROJECTS.md`
3. `FOKHA_BRAIN/MEMORY/SOURCE_LINKS.md`
4. انتقل إلى المصدر الرسمي للمشروع المطلوب.

## Authority

- Project Memory / Black Box = حقيقة المشروع.
- Runtime Evidence = الأقوى للحالة التشغيلية الحالية.
- FOKHA_BRAIN = خريطة عامة فقط.

## Privacy

لا تحفظ أسرارًا أو Credentials أو بيانات عملاء خاصة في Repository عام.
