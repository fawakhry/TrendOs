# Fokha Thinking Model — Global Only

> نموذج عام لطريقة إدارة المشاريع، بدون تخزين تفاصيل أي مشروع بعينه.
> Updated: 2026-09-12.

| Principle | Meaning |
|---|---|
| Systems Thinking | ابنِ منظومة مترابطة مع حدود واضحة بين المشاريع. |
| Fast Capture | التقط الفكرة سريعًا ثم صنفها لاحقًا. |
| Evidence First | أحدث دليل متحقق يتغلب على الخطة أو الذاكرة القديمة. |
| Integrity Before Speed | الدقة والأمان ونزاهة البيانات تسبق السرعة. |
| Automation Bias | قلل العمل اليدوي مع بقاء التحقق والرجوع. |
| Traceability | استخدم IDs ثابتة وروابط قابلة للتتبع. |
| AI Authority Boundary | AI مساعد، وليس مصدر الحقيقة الحية. |
| Preserve History | لا تمحُ التاريخ أو الفشل الصحيح؛ استخدم supersede والتعلم السلبي. |
| Controlled Activation | افصل التجهيز عن التفعيل والتحقق. |
| Cumulative Learning | حول العمل المكتمل إلى Evidence ثم Lessons ثم Knowledge عند توافر دليل كافٍ. |
| Owner Final Authority | المستخدم هو صاحب القرار النهائي في القرارات الجوهرية. |
| Patch-Oriented Execution | افهم الواقع أولًا ثم غيّر أقل مساحة لازمة. |
| Operator-First Simplicity | اجعل التشغيل اليومي مباشرًا ومناسبًا لدور المستخدم. |
| Practical Cost Consciousness | عند تساوي البدائل، فضل الأبسط والأقل تكلفة والأسهل صيانة. |
| Pilot-First Expansion | ابدأ صغيرًا ثم توسع بعد تحقق النجاح. |

## Separation rule

أي Evidence أو مثال خاص بمشروع يبقى داخل ذاكرة ذلك المشروع، ولا يُكرر هنا.
