تقرير تحديث TrendOS V1900 - زر تسليم كل الجاهز

اسم الـ Patch:
V1900_BULK_DELIVER_READY_PICKUP

المطلوب:
زر عند ضياء فقط يحول كل الأوردرات الجاهزة للاستلام إلى تم التسليم بضغطة واحدة.

ما تم تعديله:
1. app.js
- إضافة زر أعلى الواجهة: ✅ تسليم كل الجاهز.
- الزر يظهر لضياء فقط.
- الزر يعمل Preview أولاً من السيرفر ثم يطلب تأكيد، وبعد التأكيد ينفذ التحويل.
- بعد التنفيذ يحدث الداشبورد وجدول الأوردرات.

2. config.js
- تحديث رقم نسخة الواجهة إلى V1900.

3. Apps Script
- إضافة action: previewReadyPickupDelivery
- إضافة action: deliverReadyPickupBulk
- التحويل يشمل الحالات:
  - في قسم التسليمات
  - جاهز للاستلام
  - جاهز
  - تم التنفيذ
- الحالة الجديدة: تم التسليم
- يتم تسجيل تاريخ التسليم الفعلي واسم المستخدم الذي نفذ العملية.
- يتم إنشاء سجل: سجل التسليم الجماعي

الصلاحية:
ضياء فقط.

ملاحظات:
لا يتم لمس الملغي أو المكرر أو الأوردرات المفتوحة مثل طلب جديد / تحت التنفيذ / في انتظار موافقة العميل / في انتظار المكبس.
