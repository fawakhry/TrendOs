## Classification legend
- **CI**: tests/build/static validation.
- **READONLY**: probes/status/GET/read-only checks by static contract.
- **DEPLOY/MUTATION**: can deploy, promote, apply migrations, alter configuration, or call an explicitly mutating endpoint.
- **MIXED**: combines validation with optional/conditional mutation.
- **MANUAL/TEMP**: explicit manual or temporary operational workflow; inspect before reuse.
- **UNKNOWN**: static parser cannot classify safely.
