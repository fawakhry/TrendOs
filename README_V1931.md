# TrendOS V1931 Trend Master

إصدار موحّد يجمع التحديثات الخمسة المطلوبة فوق V1926، مع الحفاظ على الحسابات الحالية وعدم حذف أي بيانات.

## التحديثات المنفذة

1. **الأرشيف والاسترجاع**
   - أرشفة بنود «تم التسليم» خارج شيت التشغيل لتخفيف حجم القراءة.
   - شاشة بحث في الأرشيف واسترجاع الأوردر كاملًا أو بنوده المؤرشفة بدون تكرار.
   - الأوردر المؤرشف يظل متاحًا في `AI_Orders_View` للبحث الدقيق برقم الأوردر.

2. **سرعة الشاشات**
   - تحميل الصفحات والفلاتر من السيرفر عبر `getRowsPageV1931`.
   - إرسال الصفحة المطلوبة فقط للواجهة، مع تخزين الصفحات المجاورة مؤقتًا.
   - إبطال الكاش تلقائيًا بعد تغييرات التشغيل والأرشيف وقائمة المنع.

3. **سياسة التسليم وقائمة المنع**
   - التسليم متاح لجميع العملاء سواء عليهم فواتير قديمة أو لم يسددوا الفاتورة الحالية.
   - ضياء فقط يدير قائمة «عملاء منع التسليم بالمديونية» من مركز Trend Master.
   - العميل الموجود في القائمة يُمنع من «تم التسليم» فقط عندما يكون رصيد مديونيته أكبر من صفر.
   - عند تصفير المديونية يسمح النظام بالتسليم تلقائيًا، حتى لو ظل الاسم داخل القائمة.
   - القاعدة مطبقة على الحفظ الفردي، التحويل الجماعي، وزر تسليم كل الجاهز القديم.

4. **الرسائل والتنبيهات**
   - طابور رسائل واتساب لحالات الأوردر، التأخير، وتنبيهات المخزون.
   - مراجعة الرسالة وفتح واتساب ثم تسجيل الإرسال.
   - زر لعمل Trigger كل ساعة، متاح لضياء.

5. **المخزون، قفلة اليوم، وتقييم الموظفين**
   - عرض الخامات الأقل من حد التنبيه.
   - استمرار خصم المخزون مرة واحدة عند اعتماد فاتورة القسم.
   - معاينة موانع قفلة اليوم وتشغيل التقفيل الآمن بموافقة واحدة.
   - تقييم يومي للموظف: الإنجاز 70% والالتزام بالوقت 30%، مع حفظ لقطة يومية محدثة.

## الشيتات التي تُنشأ تلقائيًا

- `سجل تنبيهات التشغيل`
- `تقييم الموظفين اليومي`
- `عملاء منع التسليم بالمديونية`
- شيتات الأرشيف الموجودة من V1926 عند أول أرشفة.

## النشر

1. ارفع ملفات الواجهة إلى مستودع GitHub Pages الخاص بـ TrendOS.
2. استبدل كود Apps Script بمحتوى `Code.gs`.
3. أنشئ Deployment جديدًا للـ Web App بنفس صلاحيات النشر الحالية.
4. تأكد أن `TREND_API_URL` في `config.js` يشير إلى رابط Deployment الصحيح.
5. افتح رابط GitHub Pages، وليس رابط Apps Script. فتح رابط Apps Script بدون Action سيحوّل تلقائيًا إلى TrendOS بدل رسالة الخطأ القديمة.
6. من حساب ضياء: افتح مركز Trend Master واضغط «تفعيل التشغيل كل ساعة» مرة واحدة.

## الاختبار

```bash
node --check < Code.gs
node --check app.js
node tests/trendos_v1931.test.js
```
